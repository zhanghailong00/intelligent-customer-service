### app/rag/qa_chain.py（新增）

**功能**：整合检索和 LLM 生成，实现基于知识库的问答

**核心函数**：
- `build_context(query, top_k)`: 检索并构建上下文
- `get_references(query, top_k)`: 获取参考来源列表
- `answer(query, top_k, temperature)`: RAG 问答主函数
- `format_answer_with_references(result)`: 格式化带参考来源的回答

**Prompt 设计**：
```
你是智科云联的实训设备智能客服助手，专门帮助用户解决实训环境搭建、设备使用、故障排查等问题。

回答要求：
1. 基于提供的参考资料回答，确保信息准确
2. 如果资料中有明确答案，直接给出操作步骤或解决方案
3. 如果资料信息不足，诚实告知并建议用户联系人工客服
4. 不要编造或猜测不确定的信息
5. 回答要简洁明了，适合技术人员阅读
```

**为什么这样设计**：
- 明确角色定位（实训设备客服）
- 强调准确性（不能编造）
- 信息不足时诚实告知
- 结构化输出（步骤、注意事项）

## 潜在风险

| 风险 | 说明 | 缓解措施 |
|---|---|---|
| API 调用成本 | 每次问答调用 Embedding + LLM | 可考虑缓存热门问题 |
| 响应时间 | 两次 API 调用（检索 + 生成） | 可优化为流式输出 |
| 上下文溢出 | 检索结果太长超过 token 限制 | 只取 top_k=5，控制长度 |
| 幻觉问题 | LLM 可能编造信息 | Prompt 强调基于资料回答 |
