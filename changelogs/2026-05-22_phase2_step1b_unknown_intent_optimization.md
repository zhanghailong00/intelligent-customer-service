## 问题背景

用户测试时发现两个体验问题：
1. 问"今天天气怎么样"等无关问题时，系统仍然检索知识库，返回无关参考来源
2. 问"你好"、"你是谁"等打招呼时，回复"您的问题似乎与实训设备无关"，体验生硬

## 设计决策

### 为什么新增 greeting 意图而不是优化通用回复？

| 方案 | 优点 | 缺点 |
|------|------|------|
| 优化通用回复文案 | 改动小 | 打招呼和无关问题混在一起 |
| **新增 greeting 意图（采用）** | 分类精准，可针对性优化 | 多一种意图类型 |

打招呼和无关问题本质不同：打招呼需要友好引导，无关问题需要明确拒绝。分开处理体验更好。

---

## 改动详情

### app/llm/intent_classifier.py

**新增常量**：`INTENT_GREETING = "greeting"`

**更新分类 Prompt**：增加第 4 类意图 greeting（打招呼/闲聊）

**更新 `get_intent_label()`**：增加 greeting → "打招呼"

**更新测试用例**：增加"你好"、"你是谁"

### app/graph/router.py

**新增常量**：`GREETING_RESPONSE` — 打招呼的友好回复，引导用户提问

**修改 `route()` 函数**：
- 在 unknown 判断前，增加 `INTENT_GREETING` 判断
- 打招呼直接返回友好回复，不走 Agent，不检索知识库

**路由流程**：
```
意图分类 → greeting? → 友好回复（含功能引导）
          → unknown? → 通用回复
          → 其他   → Agent 执行
```

### web/app.py（无需修改）

## 测试验证

| 测试场景 | 预期结果 |
|---|---|
| "你好" | 友好回复，介绍功能，无参考来源 |
| "你是谁" | 友好回复，介绍功能，无参考来源 |
| "今天天气怎么样？" | 通用回复，无参考来源 |
| "这个箱子有什么功能？" | 产品 Agent 回答，有参考来源 |
| "传感器不亮了" | 故障 Agent 回答，有参考来源 |

---

## 面试亮点

1. **意图精细分类**：区分打招呼和无关问题，针对性回复，提升用户体验
2. **意图分级处理**：已知意图走 Agent 检索，打招呼/未知意图直接回复，避免资源浪费
3. **引导式回复**：打招呼时主动介绍系统功能，引导用户提问
